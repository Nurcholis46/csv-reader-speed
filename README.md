A faster drop-in for csv-reader 1.0.0: it reads broken CSV files exactly as the reference does, but several times faster — one left-to-right pass, regex-driven field scans, no dependencies. Answers are byte-identical to the reference on every practice case.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
